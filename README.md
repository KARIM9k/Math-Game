# 🧮 Math Game (C# WinForms)

A desktop Windows Forms mathematical quiz game built with C# and .NET Framework.

# ✨ Features
- **Multiple Game Modes:** True/False questions & Write Answer mode & Multiple Choice.
- **Player Modes:** Single Player & 2-Player competitive mode.
- **Customizable Settings:** Choose difficulty levels (Easy, Medium, Hard, Random) and operation types (Addition, Subtraction, Multiplication, Division).
- **Timer Challenge:** Configurable round timer for added excitement.
- **Score Tracking:** Real-time score updates and detailed game-over results.

# 🛠️ Built With
- C#
- .NET Framework / WinForms
